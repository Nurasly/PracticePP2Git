# Moving Ball Game

A simple interactive Pygame application where a red ball moves within the screen boundaries using arrow keys.

## Features
- **Movement**: Use `Up`, `Down`, `Left`, and `Right` arrow keys.
- **Constraints**: The ball cannot move past the window edges.
- **Visuals**: 50px diameter red ball on a white background.
